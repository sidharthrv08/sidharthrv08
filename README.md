## 📂 Projects

### 🏆 [Enterprise SOC Home Lab — Wazuh SIEM & Endpoint Telemetry](https://github.com/sidharthrv08/wazuh-soc-lab)

> Built a fully functional enterprise-grade SOC lab using **Wazuh SIEM v4.9** on VirtualBox with Ubuntu Server and Kali Linux endpoints. Engineered custom MITRE ATT&CK-mapped detection rules, adversary emulation scripts, and NIST SP 800-61 incident response playbooks.

**Key highlights:**
- 🔍 Kernel-level telemetry via Linux `auditd` (`execve` syscall monitoring)
- 🛡️ File Integrity Monitoring (FIM) on `/etc/passwd`, `/etc/shadow`, `/etc/sudoers`
- ⚡ Custom correlation rules detecting SSH brute force (T1110.001), privilege escalation (T1548.003), and defense evasion (T1070.003)
- 📋 NIST SP 800-61 Rev. 2 IR playbooks for triage, containment, and eradication
- ⚙️ Optimised for low-RAM environments (6–8 GB total host RAM)
